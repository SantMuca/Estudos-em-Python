# Projetos Solo - Python 🐍

Este repositório foi criado para organizar e documentar os meus projetos de estudo desenvolvidos em Python. O objetivo principal é consolidar conceitos fundamentais da linguagem através de aplicações práticas de terminal.

---

## 💻 Projetos Atuais

### 1. 🧮 Calculadora Contínua
Uma calculadora de terminal interativa que realiza as quatro operações matemáticas básicas (adição, subtração, multiplicação e divisão).
* **Diferencial:** Possui uma "memória" que armazena o resultado do último cálculo, permitindo que o usuário continue operando a partir dele, exatamente como em uma calculadora real. Inclui também uma opção para zerar a memória (`c`) e tratamento de erros para entradas inválidas.
* **Conceitos Praticados:** Funções, loops (`while True`), condicionais, tratamento de exceções (`try/except`) e manipulação de estados (`None`).

### 2. 📝 Gerenciador de Tarefas (To-Do List)
Um sistema de terminal completo para organização e gerenciamento de tarefas diárias.
* **Funcionalidades:** Permite adicionar novas tarefas, listar todas as tarefas salvas mostrando o status atual, marcar tarefas específicas como concluídas e remover tarefas da lista.
* **Conceitos Praticados:** Estruturas de dados avançadas (Listas e Dicionários), laços de repetição (`for` combinando `enumerate`), operadores ternários e lógica aplicada de CRUD (Create, Read, Update, Delete) em memória.
